# Logo

The 차곡차곡 logo is a red seal stamp: "차곡 / 차곡" stacked in two rows, with the ㅗ of the last 곡 drawn as a car.

| File | Use |
|---|---|
| `chagok_logo_source.png` | Original 1024 px artwork (AI-generated, then chosen by the team) |
| `chagok_stamp.png` | Stamp only, transparent background; ink #D93417, the letters are cut out |
| `chagok_icon_512.png` | 512 px app icon for store listings (stamp on paper #F5ECE0) |

In the app: `res/drawable-nodpi/chagok_stamp.png` (intro screen), `res/drawable-nodpi/chagok_icon_foreground.png`
(adaptive icon foreground), `res/mipmap-*/ic_launcher*.webp` (legacy icons). Paper color: `@color/chagok_paper`.
